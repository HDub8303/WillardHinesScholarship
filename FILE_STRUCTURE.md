# Repository layout

- `index.html`: newly created homepage
- `about.html`, `scholarship-awards.html`, `guidelines.html`, `apply.html`, `donations.html`, `press.html`, `gallery.html`, `contact.html`: reviewed pages
- `css/styles.css`, `css/pages.css`: layout and responsive styling
- `js/main.js`: mobile navigation and safeguards for unconfigured forms
- `images/`: logo, hero, signature, six original gallery photos, 57 additional archive photos, and a local Instagram SVG icon
- `documents/`: historical application and press draft PDFs
- `.nojekyll`: serves the static site without Jekyll processing
- `.gitignore`: ignores local temporary files
- `download-images.sh`: optional refresh script; not required to publish
- `README.md`, `QUICK_START.md`, `MIGRATION_GUIDE.md`, `REVIEW_REPORT.md`: documentation
