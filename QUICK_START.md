# Quick start

1. Extract `willardjhines-github-ready-v3.zip`.
2. Upload the contents of its `willardjhines` folder to a new GitHub repository. Keep all subfolders intact and include `.nojekyll`.
3. In Settings → Pages choose Deploy from a branch → main → /(root) → Save.
4. Use the URL shown by GitHub.

No image download or build command is required. See README.md for content checks and form setup. This package is ready for static hosting; online form collection and payment processing on this website are not configured; donation links and mailing details come from the reference screenshot.
